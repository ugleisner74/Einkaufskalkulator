Verteilschlüssel: Seefracht, Nachlauf, Nebenkosten und sonstige Container-Kosten werden je Artikel proportional zu dessen Anteil am genutzten Container-Volumen umgelegt. Zollwert je Artikel = Warenwert + anteilige Seefracht bis zur EU-Grenze; Nachlauf, Nebenkosten und sonstige Kosten fließen nicht in den Zollwert ein. Der Zollsatz wird einheitlich für den gesamten Container angewendet (Standard 2 %, in den Container-Einstellungen änderbar). Die Zentrallager-Kosten (Anteil von "Gesamt (EUR)", also den bereits inkl. Fracht, Zoll, Versicherung und IC-China-Gebühr ermittelten Kosten je Artikel) fließen nicht in "Gesamt (EUR)" selbst ein, sondern werden als Aufschlag auf den EUR/Stk-Preis ausgewiesen.

Cloud-Sync (geräteübergreifend arbeiten)

Standardmäßig speichert der Kalkulator alle Eingaben nur lokal im Browser (localStorage) – das gilt pro Gerät/Browser einzeln. Um dieselben Daten automatisch auf all deinen Geräten zu haben, verbindest du den Kalkulator hier einmalig mit einer kostenlosen Firebase-Cloud-Datenbank. Danach werden alle Änderungen automatisch synchronisiert.

Status: nicht verbunden – Eingaben werden nur lokal gespeichert.

Einmalige Einrichtung (ca. 5 Minuten)

  1. Auf console.firebase.google.com mit einem Google-Konto anmelden und ein neues, kostenloses Projekt anlegen.
  2. Im Projektmenü links "Firestore Database" öffnen → "Datenbank erstellen" → Modus "Testmodus" wählen (reicht zum Start) → Standort auswählen (z. B. europe-west) → erstellen.
  3. Im Reiter "Regeln" der Firestore Database den Text unten einfügen und veröffentlichen.
  4. Im Projekt-Overview (Zahnrad oben links → "Projekteinstellungen") ganz unten bei "Meine Apps" über das Symbol </> eine neue Web-App hinzufügen (Name frei wählbar). Firebase zeigt dann einen Codeblock firebaseConfig = {...} an – diesen kompletten JSON-Teil kopieren und oben in das Feld "Firebase-Konfiguration" einfügen.
  5. Einen eigenen, langen Sync-Code frei erfinden (wirkt wie ein Passwort) und oben eintragen.
  6. "Verbinden & synchronisieren" klicken. Auf jedem weiteren Gerät genau dieselbe Firebase-Konfiguration und denselben Sync-Code eintragen – die Daten gleichen sich dann automatisch ab.
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /kalkulator_sync/{syncCode} {
      allow read, write: if true;
    }
  }
}
Wichtig: Der Sync-Code ist kein echtes Passwort mit Zugriffskontrolle, sondern nur ein einfacher Schutz durch Unauffindbarkeit. Wähle ihn lang und nicht erratbar und gib ihn nicht weiter. Für sensible Daten wäre eine echte Nutzeranmeldung (Firebase Authentication) nötig – bei Bedarf kann das ergänzt werden.
